## Security Scripting Lab

This repository contains a set of cybersecurity practice tasks completed for a Prodigy Infotech internship.

Each task has its own folder and README with setup and usage details.

## Tasks

1. [Task 01 - Caesar Cipher](Task_01_caesar_cipher/Readme.md)
2. [Task 02 - Image Encryption and Decryption](Task_02_image_encryption/Readme.md)
3. [Task 03 - Password Strength Checker](Task_03_password_checker/Readme.md)
4. [Task 04 - Keylogger](Task_04_keylogger/Readme.md)
5. [Task 05 - Network Sniffer](Task_05_network_sniffer/Readme.md)

## Repository Structure

- `Task_01_caesar_cipher/` - Caesar cipher script and README
- `Task_02_image_encryption/` - Image encryption/decryption script and README
- `Task_03_password_checker/` - Password checker script and README
- `Task_04_keylogger/` - Keylogger script and README
- `Task_05_network_sniffer/` - Network sniffer script, README, and requirements file

## Notes

- Some tasks use only the Python standard library.
- The image encryption task requires `Pillow` and `numpy`.
- The keylogger task requires `keyboard`.
- The network sniffer task requires `scapy` and root or sudo privileges on Linux.
